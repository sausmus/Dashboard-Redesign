TEACHER DASHBOARD REDESIGN — PROTOTYPE 4.4 (CORRECTED PACKAGE)

This corrected package fixes a packaging mistake in the previously supplied P4.4 ZIP, which accidentally still contained the P4.3 students.html.

Included changes
----------------
1. Timeliness: each student card now has Record Late Work instead of View.
2. Record Late Work opens a modal with assignment title entry, current score, and recent late-work history.
3. Saving uses the existing DashboardData.addTimelinessEntry() API, preserving current grace, deduction, minimum-score, and history rules.
4. Clicking the student name still opens the Student Profile.
5. Students remaining popover expands to fit names on normal desktop viewports; roomy desktops use five columns. Scrolling is only a viewport-safety fallback.
6. Balanced / Random is a directly clickable pill and persists through the existing selector settings key.

Data safety
-----------
No existing storage schema was changed. shared/dashboard-data.js is byte-for-byte unchanged.
